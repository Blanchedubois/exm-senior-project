## Adding a post

1. Copy `_template.md` to `YYYY-MM-DD-short-title.md` in this folder.
2. Write the post. Images go in `blog/images/` and are linked relatively, e.g. `![caption](images/2026-10-13-figure.png)`.
3. Add a row at the top of the table above.
4. Commit and push.
