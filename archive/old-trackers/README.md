# Old trackers (July 2026)

Two snapshots of the glyph-marker tracking software taken in July 2026, before
it was rebuilt as the [Reference-Warp Tagger](../../projects/reference-warp-tagger/).

- `detection-jul-2026/`: the single-image `point_tracking_gui` (optics
  correction, glyph reading, grid mapping, dot and dash detection), the
  `Markers CAD` base design sent to the Nanoscribe in January 2026, and the
  folder the six stitched reference frames lived in. The TIFFs themselves are
  not committed.
- `strain-pairing-jul-2026/`: the same single-image app plus
  `strain_pairing_gui`, a multi-image tool that pairs points across expansions
  and maps strain. `strain_pairing_plan.md` is its design document and
  `OutputV1_Jul16/` its first run.
