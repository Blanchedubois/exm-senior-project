HARDWARE SPECIFICATIONS
=======================

ESP32-S3 Feather
----------------
Model: Adafruit Feather ESP32-S3 2MB PSRAM
Chip: ESP32-S3 (QFN56) revision v0.2
Features: WiFi, BLE, Embedded Flash 4MB (XMC), Embedded PSRAM 2MB (AP_3v3)
Crystal: 40MHz
MAC Address: cc:ba:97:1d:ff:34
I2C Pins: Default SDA/SCL

NAU7802 ADCs (9 units)
----------------------
Model: NAU7802SGI
Resolution: 24-bit
I2C Address: 0x36 (non-standard, typically 0x2A)
Supply Voltage: 3.0V (internal LDO)
Gain: 128x (configurable)
Sample Rate: 10-320 SPS (configurable)

Configuration Used:
  - Gain: 128
  - LDO: 3.0V
  - Sample Rate: 10 SPS (default)
  - Calibration: AFE calibration enabled

TCA9548A Multiplexers (2 units)
--------------------------------
Model: TCA9548A I2C Multiplexer
Channels: 8 per multiplexer
I2C Addresses:
  - MUX 1: 0x71
  - MUX 2: 0x73

Channel Assignment:
  MUX 0x71:
    - Channel 0: ADC1
    - Channel 1: ADC2
    - Channel 2: ADC3
    - Channel 3: ADC4
  
  MUX 0x73:
    - Channel 0: ADC5
    - Channel 1: ADC6
    - Channel 2: ADC7
    - Channel 3: ADC8
    - Channel 4: ADC9

RESET Pins: Pulled HIGH (active low reset)
Operating Voltage: 3.3V
Max I2C Speed: 400 kHz (supported)

I2C Bus Configuration
---------------------
Clock Speed: 400 kHz
Pull-up Resistors: 4.7kΩ typical (present on each channel)
Voltage Level: 3.3V
Bus Topology: Main bus → 2x TCA9548A → 9x NAU7802

Known I2C Addresses
-------------------
0x36 - NAU7802 ADCs (all 9, isolated by multiplexers)
0x71 - TCA9548A Multiplexer 1
0x73 - TCA9548A Multiplexer 2

Note: Address 0x36 also appears on main bus when all MUX channels are OFF.
This suggests there may be an additional device at 0x36 on the main bus,
or potential bus leakage.

Voltage Calculation
-------------------
Formula: voltage = (reading / 16777216.0) * 3.0
Where:
  - 16777216 = 2^24 (24-bit ADC)
  - 3.0 = reference voltage (adjustable based on actual reference)
  - Reading is signed 24-bit integer

Known Issues
------------
1. Subsequent reads return 0xFFFFFF after first successful read
   - Likely needs conversion start command
   - Standard NAU7802 protocol doesn't work due to address difference

2. Device at 0x36 visible on main bus with all MUX channels OFF
   - May be normal bus behavior
   - Doesn't affect multiplexed operation

3. Standard NAU7802 Arduino libraries incompatible
   - Adafruit library expects address 0x2A
   - SparkFun library expects address 0x2A
   - Custom direct I2C implementation required
